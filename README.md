# ALPHA Player

A native Windows desktop audio player with a colorful, modern interface.

## Current implementation

- Native Win32 application (C++17), no third-party UI framework
- Custom-drawn dark interface with vivid blue, violet, cyan and pink accents
- Open audio files through the Windows file picker
- Playback controls: play, pause, stop
- Playback position and seek bar
- Volume control
- Audio playback powered by Windows Media Foundation (MFPlay)

## Supported platform

- Windows 10 / Windows 11
- Visual Studio 2022 with the **Desktop development with C++** workload
- CMake 3.20+

## Build

From a Visual Studio Developer PowerShell:

```powershell
cmake -S . -B build
cmake --build build --config Release
```

Run `build\\Release\\AlphaPlayer.exe` (or the executable path generated by your CMake generator).

## Project status

This is the first working foundation. Library scanning, playlists, metadata/artwork, equalizer, global shortcuts and a more advanced audio output engine are planned for subsequent iterations.
